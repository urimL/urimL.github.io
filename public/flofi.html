🎹 FLOFI
Style Transfer 기술을 활용한 음악 변환 및 스트리밍 플랫폼

📌 Overview

  • 사용자가 업로드한 MIDI 파일을 딥러닝 모델(Groove2Groove)을 통해 Lo-Fi 스타일로 변환합니다.
  • 변환된 음원을 사용자의 취향에 맞게 실시간으로 커스터마이징(BPM, 리버브 등) 할 수 있습니다.
  • 뽀모도로 타이머, 백색 소음 등 몰입을 위한 편의 기능을 활용할 수 있습니다.
  • 캡스톤 디자인 및 창업 프로젝트 최우수상 수상

🛠 Tech Stack & 💡 Why

Flask

  • 경량성 및 모델 연동 최적화

    AI 모델과의 원활한 연동을 위해 파이썬 프레임워크인 Flask를 채택하여 서버-모델 간 데이터 흐름 최적화

Groove2Groove (AI)

  • 스타일 변환을 통한 서비스 경쟁력 확보

    기존 MIDI 파일에 Lo-Fi 특유의 감성적인 스타일을 입힌 새로운 결과물을 생성함으로써 독창적인 가치 제공

  • 사용자 중심의 음악 생성

    사용자가 원하는 곡을 집중이나 취침에 적합한 Lo-Fi 음악으로 변환하여 실시간 재생 가능

JavaScript & Tone.js

  • 정교한 오디오 데이터 조작

    Tone.js 등 Web Audio Framework를 활용하여 브라우저 환경에서 MIDI 데이터를 분석하고 실시간 오디오 이펙트 적용

👨‍💻 Role & Contribution

  • Leader

    Github, Notion 및 간트차트를 활용한 협업 프로세스 리딩

  • Frontend Development

    MIDI 데이터 분석 및 조작 로직 구현, 사용자 맞춤 오디오 이펙트 시스템 구축

  • AI Model 연동

    Groove2Groove 딥러닝 모델을 API 엔드포인트로 서버와 연동

  • Utility Features

    뽀모도로 타이머, TODO 리스트, 백색소음 등 사용자 편의 기능 구현

🚨 Trouble Shooting

정밀한 오디오 컨트롤을 위한 데이터 포맷 선정
Problem WAV 등 오디오 파일은 음원 데이터가 고정되어 있어 BPM이나 노트 단위의 정교한 조작에 한계가 있음
Solve 오디오 신호가 아닌 '음악 정보'를 담은 MIDI 형식을 채택하고, 이를 JSON 데이터로 변환/분석하여 실시간 커스터마이징 로직 구현
