📌 Overview

  • Springboot,
  • 백엔드 개발자

    ERD 설계 및 외래키 제약 조건 통한 데이터 무결성 확보

  • 기업 분석 데이터와 자기소개서, 자격증 등을 체계적으로 관리할 수 있습니다.
  • 특정 기업에 대한 예상 질문과 답변을 정리하고 연습할 수 있습니다.
  • 구글 캘린더 API를 연동하여 실시간으로 스케줄을 관리할 수 있습니다.

🛠 Tech Stack & 💡 Why

Spring Boot

  • 개발 생산성 극대화

    Auto Configuration을 통해 비즈니스 로직 설계에 더 많은 시간을 투자

  • 내장 서버 활용

    별도의 외부 WAS 설정 없이 내장된 Tomcat을 활용하여 독립적인 실행 환경 구축 및 배포 편의성 확보

RESTful API

  • 리소스 중심의 명확한 구조

    자소서, 일정, 기업 분석 등 다양하고 명확한 데이터 도메인을 직관적인 URI와 HTTP 메서드로 설계하여 프론트엔드와 효율적인 협업 환경 조성

  • Stateless

    서버가 클라이언트의 상태를 보관하지 않게 함으로써 시스템의 단순성과 서버 확장성 확보

JWT

  • 트래픽 대응을 위한 무상태 인증

    공채 시즌 등 특정 기간 사용자가 급증하는 플랫폼 특성상, 서버 세션 부담이 큰 세션 방식보다 서버 자원을 효율적으로 사용하는 JWT 기반 인증을 채택

  • 구조적 분리

    HTTP 헤더를 통해 토큰을 주고받는 방식을 통해 클라이언트와 서버의 역할을 엄격히 분리하고 REST API 원칙 준수

MySQL & Redis

  • MySQL (신뢰성)

    트랜잭션과 데이터 무결성이 필수적인 회원 정보, 자기소개서 등 핵심 RDBMS 데이터 관리

  • Redis (성능)

    만료 기간이 존재하고 잦은 I/O가 발생하는 리프레시 토큰을 인메모리 저장소에서 처리하여 토큰 재발급 API 응답 속도 최적화

👨‍💻 Role & Contribution

  • REST API 설계 및 DB 스키마 구축
  • OAuth2, JWT, Spring Security를 활용한 소셜 로그인 구현
  • JPA 기반의 자소서 및 스펙 관리 등 CRUD 구현

🚨 Trouble Shooting

  • DTO 도입을 통한 데이터 전송 최적화
Problem 엔엔티티 전체 노출로 인한 보안 취약성 및 불필요한 데이터 전송 발생
Solve 화면 목적에 맞는 전용 DTO 설계로 데이터 전송 효율성 및 API 보안 강화
  • Redis를 활용한 토큰 관리 최적화
Problem RDBMS 기반 관리 시 잦은 I/O 발생으로 토큰 재발급 응답 속도 저하 우려
Solve Redis 도입 및 TTL 기능을 활용하여 데이터 접근 속도 향상 및 자동 만료 관리 구현
  • 공통 필터를 통한 인증 누락 해결
Problem 로그인 시에만 일회성으로 인증이 수행되어, 이후 요청에서 사용자 권한을 인식하지 못하는 현상 발생
Solve 모든 요청을 가로채는 공통 인증 필터(Filter) 및 예외 핸들러를 구현하여 전역적인 인증 유지 구조로 개선
